## 2. Citation Format Comparison

### 2.1 Numeric Superscript (Nature Portfolio + TrAC)

**Used by**: TrAC, npj Clean Water, Nature Reviews Materials, Nature Medicine, Scientific Reports, Nature Reviews Bioengineering

**Format**: Superscript numbers in text, numbered reference list at end.

**Examples**:
- TrAC: `mechanisms of these compounds[1]`
- Nature Reviews: `plastic pollution^{1,2}` with `REFS ^{1,2}` in figure captions
- Nature Medicine editorial: `2020 (ref. 1)`

**Reference list format**:
```
1. Author, A. B. et al. Title. Journal Vol, pages (year).
2. Author, C. D. Title. Journal Vol, pages (year).
```

### 2.2 Author-Year (Elsevier Environmental Pollution + Palgrave)

**Used by**: Environmental Pollution, Palgrave Communications

**Format**: `(Author et al., year)` in text, alphabetical reference list at end.

**Examples**:
- Environmental Pollution: `(Brandon et al., 2019)`, `(Wang et al., 2021a; Wang et al., 2021b)`
- Palgrave: `(Lebreton et al., 2017)`, `(Geyer et al., 2017)`

**Reference list format**:
```
Author, A. B., Author, C. D., & Author, E. F. (year). Title. Journal, Vol(issue), pages. https://doi.org/...
```

### 2.3 Recommendation for Our Review

**Target journal**: TrAC Trends in Analytical Chemistry (Q1 Top, IF~12)

**Use**: Numeric citation style `[1]` (TrAC standard)

**Reference list**: Numbered, following Elsevier TrAC format:
```
[1] J. Pinto da Costa, A. Avellan, C. Mouneyrac, A. Duarte, T. Rocha-Santos, Plastic additives and microplastics as emerging contaminants: Mechanisms and analytical assessment, TrAC Trends Anal. Chem. 158 (2023) 116898.
```

## 3. Layout and Typography Comparison

### 3.1 Single-Column Layout

**Used by**: TrAC, Environmental Pollution, npj Clean Water, Scientific Reports, Palgrave Communications, Nature Medicine Editorial

**Characteristics**:
- Full-width text
- Figures embedded within text flow
- Abstract in single block (TrAC/EnvPoll) or structured (npj)
- Section headings numbered (1, 1.1, 1.1.1)

### 3.2 Two-Column Layout

**Used by**: Nature Reviews Materials, Nature Medicine (Review), Nature Reviews Bioengineering

**Characteristics**:
- Dense, compact text
- Figures span full width (break columns)
- Abstract in single block at top
- "Key points" box at start (Nature Reviews)
- Right-side "Sections" navigation (Nature Reviews Bioengineering)
- Section headings NOT numbered (Introduction, Results, etc.)

### 3.3 Typography Details

| Element | TrAC | Nature Reviews | Environmental Pollution |
|---------|------|----------------|------------------------|
| Title font | Serif, large, bold | Sans-serif, very large, bold | Serif, large, bold |
| Abstract | Single paragraph | Single paragraph | Single paragraph |

| Body font | Serif ~10pt | Sans-serif ~8pt (dense) | Serif ~10pt |

## 6. Abstract Writing Style Comparison

### 6.1 TrAC Abstract Style (Example from Paper #1)

> **Structure**: Context -> Problem -> Approach -> Findings -> Implications
> **Length**: ~200 words
> **Tone**: Formal, concise, third-person
> **No citations** in abstract

```
Plastic additives comprise a plethora of substances that serve numerous purposes
in the plastic industry... Herein, we briefly overview the current knowledge on
the underlying processes affecting these mechanisms... We also outline the potential
ecological consequences of these hazardous substances and explore some of the prevailing
analytical methodologies used for their determination... Furthermore, we highlight the
key limitations of the currently available literature and present a prospective outlook
for future research.
```

### 6.2 Nature Reviews Abstract Style (Example from Paper #5)

> **Structure**: Context -> Challenge -> Approach -> Key content -> Proposal
> **Length**: ~180 words
> **Tone**: Authoritative, forward-looking

```
Microplastic particles are ubiquitous in the environment... The key question with
no risk assessment framework to take into account the multidimensionality... We review
the current tenets in defining microplastic characteristics and effects... We propose
how exposure and effect thresholds can be aligned and quantified using probability
density functions describing microplastic particle diversity.
```

### 6.3 Recommended Abstract for Our Review (~200 words)

```
Fluorescence-based imaging has emerged as a rapid, high-throughput method for
microplastic detection and quantification, leveraging multi-channel spectral responses
and compatibility with automated image recognition. However, autofluorescence arising
from intrinsic polymer chromophores and exogenous additives represents a pervasive yet
underquantified interference source that compromises detection authenticity and
quantitative accuracy. This review systematically examines autofluorescence interference
from molecular to environmental scales: (1) polymer backbone structures and functional
groups that generate intrinsic fluorescence; (2) additive classes including optical
brighteners, UV stabilizers, and pigments that dominate emission spectra; (3) environmental
aging pathways that modify fluorescence signatures; (4) control strategies including
spectral unmixing and photobleaching; and (5) how AI image recognition both amplifies
autofluorescence biases and offers mitigation through multi-modal learning. By integrating
molecular spectroscopy, additive chemistry, and machine learning perspectives, this review
provides a mechanistic framework for improving detection authenticity and standardizing
fluorescence-based microplastic monitoring methods.
```

## 7. Key Takeaways for Our Review

### 7.1 Formatting
- **Target**: TrAC single-column, numeric citations `[1]`
- **Figures**: `Fig. 1.` format, 300+ DPI, vector preferred
- **Abstract**: ~200 words, no citations, structured flow
- **Sections**: Numbered (1, 1.1, 1.1.1)

### 7.2 Content Depth
- **TrAC reviews**: ~4000-6000 words, ~4-6 figures, ~80-120 references
- **Nature Reviews**: ~8000-10000 words, ~6-8 figures, ~150-200 references
- **Our target**: TrAC style, ~5000 words, 5 main figures + 2-3 SI figures

### 7.3 Visual Design
- Use **Coolors muted_earthy** or **soft_lavender** palette (Nature Reviews aesthetic)
- Molecular figures: ball-and-stick + orbital + electron cloud (our molecular skill)
- Mechanism diagrams: clean arrows, consistent icon style
- Data figures: colorblind-safe, error bars, statistical significance markers

### 7.4 Writing Style
- **Concise**: no filler, every sentence advances the argument
- **Mechanistic**: focus on "why" not just "what"
- **Critical**: identify knowledge gaps and methodological limitations
- **Forward-looking**: propose solutions and future directions
